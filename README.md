# GPT 5.5 + GPT Image 2 Few-Shot Prompting

This frontend landing page demo was built with Codex, GPT 5.5, GPT Image 2, and the Build Web Apps plugin.

Disclaimer: This was a casual test. I did not overthink the prompt, optimize for UX, or try to make it production-ready. This was meant to see what kind of design direction it would produce with minimal guidance.

It was created from two simple prompts on Codex:

## Prompt 1

> [Select Build Web Apps plugin on Codex] I want to remake a landing page for [Insert Example]. Use GPT Image-2 to generate a full landing page with a distinct hero image (ThreeJS) and parallax scrolling immersive experience. I should feel the full vibes of space exploration. You can use React/Vite and any other tooling libaries. This is only frontend and a single landing page so it should be fast and concise, and focused on aesthetics.

## Prompt 2

> Generate a worm style logo with the text 'COMET' and replace all mentions of [Example] with COMET. The hero is amazing, but the planet in the background is plain and boring. Can we put earth there instead? Use GPT-image-2 please so its amazing.
